This entry writes a one-line software patch note for a bug in human biology, in the terse register of a real release note: the bladder sends its low-battery warning at 3% and then immediately shuts down the whole system. It is 121 characters, well inside the 160-character gate, and it names a specific, recognisable bodily bug that makes the reader wince and laugh at once.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes the patch note to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`). Python 3.13, standard library only, no network, fully deterministic.
